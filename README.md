# FigBoost

Windows 图形界面补丁器，用于给官方原生 Figma Desktop 客户端注入汉化脚本。

这是基于官方原生客户端的补丁程序，不是第三方重打包客户端，也不替换 Figma 安装包。

当前补丁程序版本：`0.5.56`，桌面运行载荷版本：`1.2.40`。

## 使用

运行：

```powershell
.\FigBoost.exe
```

下载仓库后直接双击根目录里的 `FigBoost.exe` 即可使用，不需要进入 `dist` 目录。

界面里的主要操作：

- 重新检测：自动查找最新完整 Figma 客户端目录，跳过更新残留目录，显示 Figma 版本和补丁状态。
- 检查更新：每次启动自动检查，右上角 GitHub 图标可打开项目地址；有新版时显示绿色向上箭头，点击可打开统一更新窗口。“立即更新”一次下载 FigBoost 及其内置词库，校验后替换程序、同步已安装的词库，再重新打开 FigBoost；保留所选 Figma 路径、汉化目录和个人设置。同步词库会重启正在运行的 Figma，请先保存工作。未安装汉化时只更新 FigBoost。网络或校验失败可重试。发布目录仍保留旧版客户端所需的词库文件，新版界面不再提供独立词库更新。
- 安装或更新汉化：检测到尚未安装或运行脚本需要升级时关闭 Figma，备份 `resources\app.asar`，原地写入主进程注入 hook，并在界面选择的运行时目录生成汉化运行时。成功或失败都会弹窗提示。
- Figma 原生“检查更新”：安装汉化后，使用原生菜单中的更新入口手动检查 Figma 官方新版；确认后关闭 Figma、下载官方安装器完成更新，并自动重新安装汉化。无需安装附加功能。
- 保存路径 / 迁移到此目录：选择已有的 Figma 客户端目录时保存首选路径；选择空目录时，按钮明确显示迁移，关闭 Figma 后复制客户端并修复快捷方式。原目录保留。汉化文件存放目录需要保留，供 Figma 运行时读取。
- 重复安装：比较运行脚本与支持文件，完全相同时不关闭或重启 Figma；旧版运行脚本会刷新，个人翻译数据保留。
- 用户命名保护：页面名、文件名、项目名、团队名等用户自己命名的内容不参与自动汉化。
- 卸载汉化：强制关闭 Figma，从备份恢复原始 `app.asar`。成功或失败都会弹窗提示。

实际安装或卸载补丁时会自动强制关闭 Figma，请先保存未同步的工作。

## 说明

- 默认会自动选择 `%LOCALAPPDATA%\Figma` 下版本号最高的 `app-*` 目录。
- 备份文件名为 `resources\app.asar.figma-zh-official-preload-original`。
- Figma 更新后会创建新的 `app-*` 目录，需要对新版本重新安装补丁。
- 安装补丁后会禁用 Figma 客户端内置更新器，避免官方内置更新流程把客户端回退到旧版本；更新请使用 Figma 原生“检查更新”入口，接入 FigBoost 的更新与自动恢复汉化流程。
- 这是对官方 Figma Desktop 的非官方修改，遇到客户端启动异常时请先卸载补丁恢复。

## 词库汉化与社区补译

1. 安装或更新补丁后默认开启词库汉化。无需申请 Google Cloud、填写 API 密钥或设置字符额度。
2. 编辑器、文件页、页面菜单和桌面菜单只使用随补丁维护的 Figma 专业词库，未命中的文案保持英文，不会发送给 Google。
3. 已启用“社区 Google 补译”时，社区同样先匹配内置词库；词库未命中的安全英文文案才发送给 Google，结果经过 UI 设计术语校正后保存在本机，重启和离线时自动复用。
4. 顶部 FigBoost 菜单及“汉化设置”入口已暂停，代码注释保留。继续使用已有汉化开关和社区补译设置；全新安装沿用默认设置，不清除个人翻译缓存。

**保护边界：**不改写画布、输入值、组件变体值、页面/图层/文件/项目/组件等用户命名、字体族、插件／工具名称和代码。字体下拉选项及右侧 Tools 区域的资源名称保留原文；区域标题等 Figma 系统文案仍使用词库。第三方插件、无法识别的新区域、可能包含用户内容的动态段落保留原文，不发送翻译。安全识别仍需随 Figma 页面结构更新，不能保证所有英文都能覆盖。原生菜单和可识别的系统弹窗只使用内置词库。

**连接与缓存：**Community 补译采用固定 Google 网页翻译入口，无内置共享密钥。免密钥入口没有官方 Cloud API 的可用性保证，可能受网络、限流或接口变化影响。最多两个并发请求，每次保留独立文案边界，8 秒超时、临时故障重试一次；失败时保留原文，冷却后自动重试。已缓存的社区文字仍然可用。不会调用用户旧版 Cloud 密钥。

社区补译缓存和两个汉化开关保存在 `%LOCALAPPDATA%\FigBoost\translation\cache.json`，备份为 `cache.json.bak`，最多保留 10,000 条机器结果。升级时会保留已学习的机器译文，并丢弃旧版排除规则和区域模式；旧版在非社区区域产生的机器缓存不会再使用，新产生的机器缓存只有社区文案。旧版 `state.json` 及加密凭据不再读取。更新和卸载默认保留个人数据。内置词库随桌面载荷发布并优先匹配，不会覆盖或改写用户缓存文件。

通过更新入口下载的词库保存在 `%LOCALAPPDATA%\FigBoost\updates\payload.json`，只在比当前 exe 内置词库更新且兼容时使用；重新安装补丁也会沿用该版本。词库包同时包含配套汉化运行文件。更新过程中写入失败会恢复原运行文件；保留个人翻译缓存、已有附加功能配置和 Figma 文件；旧安装缺少配置时仅补充更新程序路径，不开启附加功能。

实现参考 [TWP / Translate Web Pages](https://github.com/FilipePS/Traduzir-paginas-web) 的动态翻译、请求合并与缓存思路，以及 [KISS Translator](https://github.com/fishjar/kiss-translator) 的免密钥 Google 接入方式；针对 Electron 独立实现，没有复制完整扩展或使用其共享密钥。

验证采用合成 DOM、独立隐藏 Electron 环境，以及真实 Figma 网页的脚本注入测试。网页测试覆盖图层切换时的属性面板重建；真实桌面客户端由使用者验收。免密钥生产请求路径已用公开测试文案验证。

## 开发和测试

安装开发依赖并运行行为、安装和独立 Electron 回归：

```powershell
npm ci
npm test
npm run test:electron
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

测试依赖只用于开发，不随 exe 分发。安装自测对 Figma 进程控制已隔离，不会关闭或启动真实客户端。

单独运行安装回归测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\FigBoost.ps1 -SelfTest
```

重新打包 exe：

```powershell
Install-Module ps2exe -Scope CurrentUser
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

打包会同时生成 `updates/latest.json` 和 `updates/payload.json`。发布时将它们与本次生成的根目录 `FigBoost.exe` 一起提交推送到 `main`；更新入口从该公开仓库读取同一次提交内的版本和文件，用 SHA-256 和文件大小校验下载。若使用 `-OutputPath` 打包到临时目录，须先将生成的 exe 复制到仓库根目录再提交。发布不兼容的运行文件时，需同步提高打包脚本中的 `minPatcherVersion`。旧版（0.5.25 及以前）需先手动下载一次新版才能使用此入口。
