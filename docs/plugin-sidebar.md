## 压缩包解析

用户提供的 `Figma+汉化+EX(Windows) (2).zip` 是 Figma Electron 发布目录，侧边栏在 `resources/node_modules/fg01/js/figmaEX.js` 的压缩发布脚本中，标识为 Moonvy FigmaEX 1.5.100。压缩包没有提供对应的原始 Vue 工程。分析时只解压并阅读脚本、清单和 ASAR，未运行对方程序。

侧边栏依赖三部分：Figma 当前登录会话的资源收藏接口、原生最近插件记录，以及 Figma 自身的插件菜单。原发布脚本还带有账号、云分组、付费、皮肤等逻辑。功能层采用独立小模块，参考接口与菜单行为实现，不加载对方整份 Vue 发布脚本及账号服务。0.5.56 按用户要求直接沿用原包侧边栏 CSS 和图标，替换 0.5.55 的自绘外观。

## 已接入的功能

- Design 编辑页右侧使用原版 54px 图标栏，悬停头部或点击原版彩色图标展开 400px 面板，左侧分组 160px、右侧插件区 240px；插件行高 44px，32px 图标在右侧。跟随原版浅色/深色主题，保留高度调节。
- 同步 Figma 已保存插件；读取最近使用插件；搜索名称和简介。
- 本地星标；新建、改名、删除分组；加入分组及从分组移除。删除分组不删除插件。
- 调用 Figma 原生菜单运行插件，支持多级子命令，也支持原生菜单中可直接运行的最近插件。
- 自定义分组和星标保存在当前浏览器/客户端本地；可识别账号时分开存储，无法识别时使用本地默认分区。浏览器与桌面客户端之间不做云同步。

入口文件是 `payload/src/content/plugin-sidebar.js`。桌面构建器将它放进 `i.js`，浏览器扩展清单也会加载它。更新包增加该文件，因此最低补丁器版本提升至 0.5.55，避免旧更新器按旧文件数量拒绝载荷。

## 修复与防护

| 问题 | 参考发布脚本中的证据或触发条件 | 当前处理 |
| --- | --- | --- |
| 菜单等待不结束 | `when` 工具（模块 70544）的开始时间变量未赋值，时间差为 NaN | 实际记录开始时间，菜单每层等待最多 1.8 秒；失败恢复按钮，不记录运行成功 |
| 删除分组后刷新又出现 | `ExActions.deleteGroup` 删除内存数据后未触发本地保存 | 创建、改名、删除、成员变更均立即保存；重新加载验证删除结果 |
| 翻页地址错误 | 下一页可能是相对或绝对地址，原实现直接拼接 | 用 URL 解析，限定同源 API，去重并检测循环 |
| 同步失败清空列表 | 参考实现把异常转为空数组 | 完整读取成功后才替换收藏成员，失败保留旧缓存 |
| 重复启动、切页后残留 | 重复注入、异步接口和菜单等待跨页面返回 | 单次请求/启动；实例销毁、请求取消、代次校验 |
| 子命令与最近记录异常 | 多级菜单、未收藏的最近插件、最近接口与收藏混用 | 保存完整命令路径；优先原生最近入口；最近元数据不改变收藏成员 |
| 本地保存失败仍提示成功 | 存储配额不足 | 保留明确错误提示，不再覆盖为成功文案 |
| 最近列表图标缺失 | 原生接口返回 `/community/icon?...` 相对地址 | 转换为完整 HTTPS 地址，并拒绝脚本协议 |

侧边栏使用 Shadow DOM 隔离样式，通过文本节点渲染名称；输入事件不会继续传播到画布快捷键。状态文案只表示已发送原生菜单操作，不把第三方插件环境是否加载成功伪装成已确认。

## 原版样式来源（0.5.56）

直接提取所提供 ZIP 的 `fg01/js/figmaEX.js` 中 CSS 模块 15401（ExBar）、25116（ActionItem）、74692（GroupPad）及共享深色主题，沿用原有尺寸、字体、颜色、圆角、悬停和滚动条规则，以及内嵌的彩色入口、设置和星标图标。只保留侧边栏用到的选择器；将 body 主题选择器映射到 Shadow DOM，将 div 控件选择器映射到可键盘操作的 button。原菜单外观之外的少量适配只负责挂载位置、焦点、现有分组编辑和错误反馈，不引入另一套主界面设计。

已移除 0.5.55 的“插件”文字入口、大标题栏、常驻底部状态栏、左侧插件图标和紫色自绘配色。成功状态保留给辅助技术读取，错误仍可见；原有本地分组和星标数据继续复用。
